# Demo Script

## 30-second opening

Mantle Agent Radar is an AI Alpha & Data agent for Mantle investors. It turns noisy Telegram, social, and Mantle-native on-chain sources into ranked, verifiable alpha/risk signals.

Every high-confidence signal has evidence, a recommended investor action, and a hash that can be committed to Mantle.

## Demo flow

1. Open the dashboard.
2. Show the top signal: why it matters, confidence, evidence, and scoring.
3. Filter to competitor/risk/deployment signals.
4. Show how the agent converts raw Telegram/DevHub/criteria data into investor-grade insight.
5. Show `contracts/SignalRegistry.sol` and explain the on-chain hash proof.
6. Close with monetization: real-time alerts for funds and protocol teams.

## Prize framing

- Track 02, AI Alpha & Data.
- Mirana criteria fit:
  - novel insights;
  - unique Mantle-native source quality;
  - investment utility;
  - scalable live data pipelines.
- Deployment path: commit signal hashes to Mantle mainnet.
- Community path: publish live signal cards on X.
