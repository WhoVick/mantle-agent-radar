# Mantle Agent Radar

## What It Is

Mantle Agent Radar is an AI Alpha & Data agent that ranks Mantle-native alpha, risk, ecosystem, competitor, and deadline signals for investors and builders.

It ingests Telegram/DevHub/criteria/on-chain evidence, scores each signal, shows the rationale in a dashboard, and can commit high-confidence signal hashes to Mantle through `SignalRegistry`.

## Demo Steps

1. Open the deployed dashboard.
2. Select the top signal.
3. Show confidence score and evidence.
4. Filter competitor/risk/ecosystem signals.
5. Show `contracts/SignalRegistry.sol`.
6. Show a signal hash generated by `python tools/hash_signal.py --top`.
